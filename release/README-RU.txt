ACC Sectors 0.2.2 — Windows x64

ЗАПУСК
1. Запустите ACC-Sectors.exe двойным щелчком. Установка не нужна.
2. Откройте Assetto Corsa Competizione в оконном режиме без рамки.
3. Переместите панель мышью. Настройки открываются кнопкой снизу слева.
4. Закрыть панель: правая кнопка -> Закрыть, либо Escape в выбранном окне.

Для общего лучшего круга и ближайших машин включается локальный ACC Broadcasting.
Если программа просит перезапустить ACC, полностью закройте игру и откройте заново.
Сравнения с прошлым кругом требуют записанного круга с работающим оверлеем.
Временные отрывы ближайших машин на трассе оценочные и обозначены знаком ≈.

Настройки, положение панели и журнал запуска:
%LOCALAPPDATA%\ACC Sectors\Data
История кругов находится в памяти до закрытия программы или смены сессии.
Личные настройки и файлы ACC в релиз не включены.

Дополнительные режимы:
ACC-Sectors.exe --demo       — демонстрация без игры
ACC-Sectors.exe --self-test  — проверки, результат в Data\launch.log
ACC-Sectors.exe --preview    — создать демонстрационный preview.png в Data

ТРЕБОВАНИЯ
Windows 10/11 x64, стандартные Windows PowerShell 5.1 и .NET Framework 4.8.
PowerShell 7, Python и отдельный .NET SDK не требуются.
Все рабочие файлы встроены в EXE и распаковываются в профиль пользователя.
Видимой консоли при запуске нет. EXE не имеет цифровой подписи издателя.

График дельты: Настройки → Показывать график дельты после круга.
Выключен по умолчанию. Включение применяется сразу. Показ — общий пятисекундный интервал результата после финиша.
Для проверки без ACC: ACC-Sectors.exe --preview (принудительно показывает график без сохранения настройки).


Для разработчиков: интерактивный тестер со случайными кругами доступен в исходном коде репозитория (Test.cmd). В этот EXE и ZIP он не включён. Обычная демонстрация: ACC-Sectors.exe --demo.
