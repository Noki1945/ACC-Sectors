# ACC Sectors

Компактный оверлей для Assetto Corsa Competizione на Windows. Работает через shared memory, без установки файлов в игру и без дополнительных библиотек.

## Запуск

1. Дважды нажмите `Start.cmd`.
2. Запустите ACC в оконном режиме без рамки, выйдите на трассу.
3. Перетащите панель мышью в удобное место. Положение сохраняется. Для закрытия — Escape при выбранном окне или правая кнопка → «Закрыть».

Посмотреть оформление без игры: `Start.cmd -Demo`.

## Показатели

- S1–S3: активный сектор считает время вживую, с тремя знаками после точки. Завершённые сектора фиксируются. Каждый сектор имеет отдельную длительность: S2 = второй накопленный сплит минус S1; S3 = время круга минус S1 и S2. Под завершённым сектором — разница с тем же сектором предыдущего круга. Зелёный — быстрее, красный — медленнее, белый — разница в пределах ±0,020 с или ещё нет сравнения. Основные времена и подписи белые, увеличенного размера; фон на 70% прозрачный.
- КРУГ: текущий секундомер круга. После финиша на 5 секунд фиксируются полный круг, три сектора и разница с предыдущим кругом. Следующий круг уже записывается в фоне. Через 5 секунд появляются его актуальные значения: например, S1 = 5.100, а не искусственный старт с нуля после задержки. Будущие сектора остаются прочерками.
- BEST: личный лучший круг сессии из ACC; пустое значение пакета не стирает результат. Если ACC его ещё не опубликовал, оверлей использует полный действительный круг, записанный с начала. BEST* — лучший замеченный завершённый круг, когда действительный результат ещё неизвестен; он может быть недействительным. Подробность видна при наведении мыши.
- КРУГОВ: количество завершённых кругов.
- Нижняя дельта: текущий отрыв от предыдущего круга в той же точке трассы. Минус — быстрее, плюс — медленнее. «ЗАПИСЬ КРУГА» — пока нет предыдущей записи. «НЕТ ДАННЫХ В ТОЧКЕ» — запись есть, но в этой части трассы её нет или слишком большой разрыв между пакетами. Если оверлей подключён посреди круга, на следующем круге дельта доступна только в записанной части; полный круг даёт полное покрытие. После финиша на 5 секунд показывается разница полных кругов.

Обновление окна — примерно 60 раз в секунду, по фактической телеметрии игры; отображение тысячных не означает получение 1000 пакетов в секунду. В паузе секундомеры не накручиваются самостоятельно. При подключении посреди круга неизвестные сектора отображаются прочерками. Смена типа или индекса сессии, сброс счётчика и возврат в меню очищают сравнения. Переход в повтор также очищает запись, чтобы не смешивать её с ездой. Круги с нарушением границ трассы участвуют в сравнении с предыдущим кругом.

Оверлей предназначен для обычного экрана, не VR. Эксклюзивный полноэкранный режим может перекрывать окно. Панель принимает мышь для перемещения.

## Проверка

`Start.cmd -SelfTest` — проверка живого хронометража, задержки на финише, расчёта отдельных секторов, запаздывающих пакетов, BEST, сброса сессии, полной/частичной записи дельты и чтения полей памяти.

`Start.cmd -Preview` — создать `preview.png` с демонстрационными данными и закрыть окно.

Формат памяти: [документация ACC в PyAccSharedMemory](https://github.com/rrennoir/PyAccSharedMemory/blob/main/ACCSharedMemoryDocumentationV1.8.12.pdf). Читаются только graphics-поля; доступ к памяти открыт только на чтение.
