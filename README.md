# ACC Sectors

Компактный оверлей для Assetto Corsa Competizione на Windows. Личный хронометраж читает shared memory; лучший круг всех участников — локальный ACC Broadcasting API. Дополнительные библиотеки не нужны.

## Запуск

1. Дважды нажмите `Start.cmd`.
2. Запустите ACC в оконном режиме без рамки, выйдите на трассу.
3. Перетащите панель мышью в удобное место. Положение сохраняется. Для закрытия — Escape при выбранном окне или правая кнопка → «Закрыть».

Посмотреть оформление без игры: `Start.cmd -Demo`.

## Настройки панели

Кнопка «⚙ Настройки» находится снизу слева. Она открывает отдельное небольшое окно:

- «Затемнение фона»: от 0% (полностью прозрачный фон) до 100% (непрозрачный). По умолчанию 30% затемнения, то есть 70% прозрачности. Текст остаётся непрозрачным.
- «Показывать прошлый круг»: скрывает или возвращает время последнего завершённого круга под BEST. Сравнения под секторами и временем круга остаются видны.

Изменения применяются сразу и сохраняются в `preferences.json` рядом с программой. «Готово», крестик или Escape закрывают настройки, оставляя оверлей работающим.

## Позиции в самой ACC

Страницы MFD обычно переключаются клавишей Insert. Если она переназначена, откройте настройки управления и найдите «Cycle HUD MFD Up» / переключение страниц MFD; действие можно назначить на руль.

Standings — зачёт сессии: в квалификации он определяется лучшими действительными кругами, в гонке — пройденной дистанцией и порядком машин. Relative / Realtime — ближайшие машины по расположению на трассе: среди них могут быть круговые, поэтому порядок не обязан совпадать с зачётом. Для смешанных классов есть отдельные представления класса и общего зачёта. [Официальные примечания ACC о MFD и классах](https://assettocorsa.gg/acc-v1-5-and-gt4-pack-dlc/).

Отдельное окно позиций в этот выпуск не добавлено: здесь используется штатный MFD игры.

## Показатели

- В верхней строке между названием и статусом: слева `↑ ≈1.234` — ближайшая машина впереди **на трассе**, справа `↓ ≈0.875` — ближайшая сзади. Соседи определяются по положению вдоль круга, независимо от позиции в зачёте и количества пройденных кругов; круговые учитываются, пит-лейн исключён. Используется кратчайшее направление по трассе, включая переход через старт/финиш. Временной отрыв оценивается из доли круга и времени круга игрока, поэтому отмечен «≈»; это не официальный гоночный интервал. Пока времени круга нет, при доступной длине трассы показываются метры. Требуется подключение ACC Broadcasting и свежие координаты машин; при их отсутствии — прочерк. Поля gapAhead/gapBehind для этого индикатора не используются.
- S1–S3: активный сектор считает время вживую, с тремя знаками после точки. Завершённые сектора фиксируются. Каждый сектор имеет отдельную длительность: S2 = второй накопленный сплит минус S1; S3 = время круга минус S1 и S2. Под сектором крупным шрифтом — разница с тем же сектором предыдущего круга. После финиша она остаётся на 5 секунд вместе с временами секторов, затем очищается. На новом круге сравнения появляются только по мере завершения его секторов. Зелёный — быстрее, красный — медленнее, белый — разница в пределах ±0,020 с. Прочерк означает, что сравнение ещё неизвестно. Основные времена и подписи белые; фон по умолчанию на 70% прозрачный.
- КРУГ: текущий секундомер круга. После финиша на 5 секунд фиксируются полный круг, три сектора и разница с предыдущим кругом. Следующий круг уже записывается в фоне. Через 5 секунд появляются его актуальные значения: например, S1 = 5.100, а не искусственный старт с нуля после задержки. Будущие сектора остаются прочерками.
- BEST: «мой лучший / лучший всех участников текущей сессии». Личный лучший берётся из ACC; пустое значение пакета не стирает результат. Если ACC его ещё не опубликовал, оверлей использует полный действительный круг, записанный с начала. BEST* — лучший замеченный завершённый круг, когда действительный результат ещё неизвестен; он может быть недействительным. Общий лучший берётся только из ACC Broadcasting, без подмены личным результатом. Прочерк справа означает отсутствие действительного результата или подключения; причина видна при наведении.
- КРУГОВ: количество завершённых кругов.
- Под КРУГ: текущая разница с предыдущим кругом в той же точке трассы. После финиша на 5 секунд показана разница последних двух завершённых кругов. Затем — только текущая дельта, без подстановки результата прошлого круга. Минус — быстрее, плюс — медленнее. Для полной текущей дельты нужно записать полный круг.
- ПРОШЛЫЙ КРУГ: время последнего завершённого круга, которое сохраняется и при временно пустом значении телеметрии.

### Собственная история и прогноз

Оверлей хранит завершённые круги текущей сессии в своей памяти: полный круг, три отдельных сектора и признаки приблизительного измерения. Разница завершённого сектора — его новое время минус записанное время того же сектора прошлого круга. На финише аналогично вычитаются два полных круга. Очистка цифр на экране через 5 секунд не удаляет эту историю. При смене сессии или закрытии программы история очищается.

Если поле сплита ACC опаздывает или отсутствует, граница сектора записывается по текущему секундомеру при смене сектора. Поздний официальный сплит уточняет результат. При восстановлении время имеет погрешность частоты опроса; такие сравнения обозначены «≈». Для полного круга сначала используется результат ACC, а при его отсутствии — оценка по переходу секундомера через финиш, также с признаком приблизительности. Если оверлей подключён посреди круга или пропущена сама граница, неизвестные сектора остаются прочерками.

Под временем круга показан «ПРОГН.»: время прошлого круга плюс текущая разница в той же точке трассы. При недостатке точек используется разница по завершённым секторам; более редкие позиционные отсчёты могут дать оценку «≈». До накопления сравнений время прошлого круга служит исходным ориентиром. Прогноз не гарантирует итоговый результат. После финиша на время показа результата прогноз скрывается.

Счётчик кругов находится строкой ниже BEST, рядом со временем прошлого круга. Подсказка под дельтой объясняет, какое сравнение сейчас используется.

Переход через финиш учитывает раздельное обновление счётчика, секундомера и позиции ACC: задержавшееся поле больше не очищает запись прошлого круга. Если сравнение недоступно, под временем круга отображается «НЕТ ЗАПИСИ» или «НЕТ ТОЧКИ». Наведение показывает количество записанных кругов и точек. Во время работы каждые 2 секунды обновляется локальный `timing-status.json` с текущим состоянием расчёта; демонстрационный режим этот файл не создаёт. Это диагностический снимок, не сохранённая между запусками история кругов.

Для общего лучшего при запуске включается порт ACC Broadcasting в `Документы\Assetto Corsa Competizione\Config\broadcasting.json`, если он был отключён. Исходный файл сохраняется как `broadcasting.json.acc-sectors.bak`; существующие пароли и включённый порт сохраняются. После первого включения перезапустите ACC. Оверлей подключается только к локальному компьютеру; команды управления машиной, камерой или интерфейсом не отправляются. Протокол: [Kunos Broadcasting SDK v4](https://github.com/nicholasxuu/ACC_broadcasting/blob/master/ksBroadcastingNetwork/BroadcastingNetworkProtocol.cs).

Обновление окна — примерно 60 раз в секунду, по фактической телеметрии игры; отображение тысячных не означает получение 1000 пакетов в секунду. В паузе секундомеры не накручиваются самостоятельно. При подключении посреди круга неизвестные сектора отображаются прочерками. Смена типа или индекса сессии, сброс счётчика и возврат в меню очищают сравнения. Переход в повтор также очищает запись, чтобы не смешивать её с ездой. Круги с нарушением границ трассы участвуют в сравнении с предыдущим кругом.

Оверлей предназначен для обычного экрана, не VR. Эксклюзивный полноэкранный режим может перекрывать окно. Панель принимает мышь для перемещения.

## Проверка

`Start.cmd -SelfTest` — проверка живого хронометража, задержки на финише, расчёта отдельных секторов, ранних/запаздывающих пакетов, сохранения сравнений, BEST, сброса сессии, записи дельты, чтения памяти и ACC Broadcasting через тестовый локальный UDP-сервер.

`Start.cmd -Preview` — создать `preview.png` с демонстрационными данными и закрыть окно.

Формат памяти: [документация ACC в PyAccSharedMemory](https://github.com/rrennoir/PyAccSharedMemory/blob/main/ACCSharedMemoryDocumentationV1.8.12.pdf). Читаются только graphics-поля; доступ к памяти открыт только на чтение.
