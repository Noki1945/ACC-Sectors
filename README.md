# ACC Sectors

Компактный оверлей для Assetto Corsa Competizione на Windows. Личный хронометраж читает shared memory; лучший круг всех участников — локальный ACC Broadcasting API. Дополнительные библиотеки не нужны.

## Запуск

[Скачать актуальный релиз для Windows x64](https://github.com/Noki1945/ACC-Sectors/releases/latest): ACC-Sectors.exe или ZIP. EXE запускается двойным щелчком без видимой консоли, все рабочие файлы встроены. Требуются стандартные Windows PowerShell 5.1 и .NET Framework 4.8 (Windows 10/11 x64). Программа не подписана цифровой подписью издателя.

В EXE-версии настройки и журнал находятся в `%LOCALAPPDATA%\ACC Sectors\Data`, встроенные файлы — в отдельном каталоге Runtime этого же профиля. Положение и настройки сохраняются между обновлениями EXE. Личные настройки из папки разработки в релиз не включаются. Для демонстрации: `ACC-Sectors.exe --demo`.

Запуск исходной версии для разработки:

1. Дважды нажмите `Start.cmd`.
2. Запустите ACC в оконном режиме без рамки, выйдите на трассу.
3. Перетащите панель мышью в удобное место. Положение сохраняется. Для закрытия — Escape при выбранном окне или правая кнопка → «Закрыть».

Посмотреть оформление без игры: `Start.cmd -Demo`.

Собрать релиз заново стандартным компилятором .NET Framework:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-Release.ps1
```

Скрипт создаёт EXE, проверяет встроенные тесты и формирует ZIP и `SHA256SUMS.txt` в `dist`. Перед публикацией сверяйте контрольные суммы готовых файлов. История изменений: [CHANGELOG.md](CHANGELOG.md).

## Настройки панели

Кнопка «⚙ Настройки» находится снизу слева. Она открывает отдельное небольшое окно:

- «Затемнение фона»: от 0% (полностью прозрачный фон) до 100% (непрозрачный). По умолчанию 30% затемнения, то есть 70% прозрачности. Текст остаётся непрозрачным.
- «Показывать прошлый круг»: скрывает или возвращает время последнего завершённого круга под BEST. Сравнения под секторами и временем круга остаются видны.
- «Соседние машины»: «На трассе» (по умолчанию) или «По позиции». Меняет выбор машин в индикаторах ↑ / ↓ сразу, без перезапуска.
- «Сравнение времени круга»: «Автоматически» (по умолчанию), «Предыдущий круг» или «Личный лучший круг». Меняет эталон дельты под КРУГ и прогноза. Под списком указан фактически активный режим. Секторные сравнения продолжают использовать предыдущий круг.

Изменения применяются сразу и сохраняются в `preferences.json` рядом с программой. «Готово», крестик или Escape закрывают настройки, оставляя оверлей работающим.

Старые файлы совместимы: отсутствующие `TrafficMode` / `ComparisonMode` получают `Track` / `Automatic`. Допустимые значения — `Track` / `Position` и `Automatic` / `Previous` / `PersonalBest`. Известные старые параметры затемнения и прошлого круга сохраняются. В EXE-версии используется файл из `%LOCALAPPDATA%\ACC Sectors\Data`.

### Соседи по классификации и точность интервалов

«На трассе» выбирает ближайших по кратчайшему направлению вдоль круга, не учитывая их место и число кругов; пит-лейн исключён. «По позиции» использует именно `Position` из ACC Broadcasting: для игрока P5 выбираются P4 и P6, независимо от расположения, включая участников в питах. Car ID служит только идентификатором, номер автомобиля не используется для сортировки.

В Practice, Qualifying, Superpole и Hotlap при наличии действительных лучших времён обоих участников выводится разница этих времён без «≈». В гонке интервал оценивается по полной пройденной дистанции (круги + положение на круге) и опорному времени круга; он всегда помечается «≈». Это не официальный динамический гоночный gap. При недостоверной дистанции, нахождении в питах, отсутствующем времени или неподдержанном формате сессии показывается прочерк. Машина при этом выбирается по позиции, а не заменяется физически ближайшей. Дублирующиеся позиции в несинхронных пакетах и данные старше 2 секунд не используются для угадывания соседей.

### Эталон времени круга

Автоматический режим использует тип сессии из Shared Memory:

| Сессия | Эталон |
|---|---|
| Practice (0), Race (2) | Предыдущий круг |
| Qualifying (1), Hotlap (3), Hotstint (7) | Личный лучший круг |
| Остальные и неизвестные | Предыдущий круг |

Ручной выбор автоматикой не переопределяется. Смена сессии очищает записи и выбирает новый эталон; данные разных сессий не смешиваются. На старте каждого круга фиксируются время и позиционные точки эталона. Новый личный рекорд становится эталоном следующего круга: финальная дельта нового рекорда считается относительно прежнего, а не самого себя. Явное переключение режима пользователем применяется сразу; уже зафиксированный пятисекундный результат не пересчитывается.

Личный эталон хранится только для полного действительного круга с записанными точками и подтверждённым временем. Недействительные круги могут участвовать в сравнении с предыдущим, но не обновляют личный лучший эталон. Если ACC сообщает более быстрый рекорд, поставленный до запуска оверлея, его неизвестные точки не восстанавливаются из предыдущего круга. До записи соответствующего или нового лучшего круга живая дельта и прогноз недоступны; итоговую разницу на финише можно получить по известным полным временам.

Точки сопоставляются по одинаковой позиции на трассе с интерполяцией между соседними отсчётами. Пропуски до 30 секунд допускают только помеченную оценку; большие разрывы не интерполируются. При наличии завершённых секторов может выводиться их накопленная разница с выбранным эталоном, также с «≈». Прошлый круг и личный рекорд хранят независимые копии данных только в памяти.

## Показатели

- В верхней строке между названием и статусом в режиме «На трассе»: слева `↑ ≈1.234` — ближайшая машина впереди **на трассе**, справа `↓ ≈0.875` — ближайшая сзади. Соседи определяются по положению вдоль круга, независимо от позиции в зачёте и количества пройденных кругов; круговые учитываются, пит-лейн исключён. Используется кратчайшее направление по трассе, включая переход через старт/финиш. Временной отрыв оценивается из доли круга и времени круга игрока, поэтому отмечен «≈»; это не официальный гоночный интервал. Пока времени круга нет, при доступной длине трассы показываются метры. Требуется подключение ACC Broadcasting и свежие координаты машин; при их отсутствии — прочерк. Поля gapAhead/gapBehind для этого индикатора не используются.
- S1–S3: активный сектор считает время вживую, с тремя знаками после точки. Завершённые сектора фиксируются. Каждый сектор имеет отдельную длительность: S2 = второй накопленный сплит минус S1; S3 = время круга минус S1 и S2. Под сектором крупным шрифтом — разница с тем же сектором предыдущего круга. После финиша она остаётся на 5 секунд вместе с временами секторов, затем очищается. На новом круге сравнения появляются только по мере завершения его секторов. Зелёный — быстрее, красный — медленнее, белый — разница в пределах ±0,020 с. Прочерк означает, что сравнение ещё неизвестно. Основные времена и подписи белые; фон по умолчанию на 70% прозрачный.
- КРУГ: текущий секундомер круга. После финиша на 5 секунд фиксируются полный круг, три сектора и разница с предыдущим кругом. Следующий круг уже записывается в фоне. Через 5 секунд появляются его актуальные значения: например, S1 = 5.100, а не искусственный старт с нуля после задержки. Будущие сектора остаются прочерками.
- BEST: «мой лучший / лучший всех участников текущей сессии». Личный лучший берётся из ACC; пустое значение пакета не стирает результат. Если ACC его ещё не опубликовал, оверлей использует полный действительный круг, записанный с начала. BEST* — лучший замеченный завершённый круг, когда действительный результат ещё неизвестен; он может быть недействительным. Общий лучший берётся только из ACC Broadcasting, без подмены личным результатом. Прочерк справа означает отсутствие действительного результата или подключения; причина видна при наведении.
- КРУГОВ: количество завершённых кругов.
- Под КРУГ: текущая разница с выбранным эталоном в той же точке трассы. После финиша на 5 секунд показана итоговая разница с эталоном, зафиксированным на старте. Минус — быстрее, плюс — медленнее. Без позиционных точек личного рекорда живая дельта не подменяется прошлым кругом.
- ПРОШЛЫЙ КРУГ: время последнего завершённого круга, которое сохраняется и при временно пустом значении телеметрии.

### Собственная история и прогноз

Оверлей хранит завершённые круги текущей сессии в своей памяти: полный круг, три отдельных сектора и признаки приблизительного измерения. Разница завершённого сектора — его новое время минус записанное время того же сектора прошлого круга. На финише аналогично вычитаются два полных круга. Очистка цифр на экране через 5 секунд не удаляет эту историю. При смене сессии или закрытии программы история очищается.

Если поле сплита ACC опаздывает или отсутствует, граница сектора записывается по текущему секундомеру при смене сектора. Поздний официальный сплит уточняет результат. При восстановлении время имеет погрешность частоты опроса; такие сравнения обозначены «≈». Для полного круга сначала используется результат ACC, а при его отсутствии — оценка по переходу секундомера через финиш, также с признаком приблизительности. Если оверлей подключён посреди круга или пропущена сама граница, неизвестные сектора остаются прочерками.

Под временем круга показан «ПРОГН.»: время выбранного эталона плюс текущая разница в той же точке трассы. При недостатке точек используется помеченная разница по завершённым секторам. В режиме предыдущего круга его время может служить исходным ориентиром; в режиме личного лучшего при неизвестных точках прогноз скрывается. После финиша на время показа результата прогноз также скрывается.

Счётчик кругов находится строкой ниже BEST, рядом со временем прошлого круга. Подсказка под дельтой объясняет, какое сравнение сейчас используется.

Переход через финиш учитывает раздельное обновление счётчика, секундомера и позиции ACC: задержавшееся поле больше не очищает запись прошлого круга. Если сравнение недоступно, под временем круга отображается «НЕТ ЗАПИСИ» или «НЕТ ТОЧКИ». Наведение показывает количество записанных кругов и точек. Во время работы каждые 2 секунды обновляется локальный `timing-status.json` с текущим состоянием расчёта; демонстрационный режим этот файл не создаёт. Это диагностический снимок, не сохранённая между запусками история кругов.

Для общего лучшего при запуске включается порт ACC Broadcasting в `Документы\Assetto Corsa Competizione\Config\broadcasting.json`, если он был отключён. Исходный файл сохраняется как `broadcasting.json.acc-sectors.bak`; существующие пароли и включённый порт сохраняются. После первого включения перезапустите ACC. Оверлей подключается только к локальному компьютеру; команды управления машиной, камерой или интерфейсом не отправляются. Протокол: [Kunos Broadcasting SDK v4](https://github.com/nicholasxuu/ACC_broadcasting/blob/master/ksBroadcastingNetwork/BroadcastingNetworkProtocol.cs).

Обновление окна — примерно 60 раз в секунду, по фактической телеметрии игры; отображение тысячных не означает получение 1000 пакетов в секунду. В паузе секундомеры не накручиваются самостоятельно. При подключении посреди круга неизвестные сектора отображаются прочерками. Смена типа или индекса сессии, сброс счётчика и возврат в меню очищают сравнения. Переход в повтор также очищает запись, чтобы не смешивать её с ездой. Круги с нарушением границ трассы участвуют в сравнении с предыдущим кругом.

Оверлей предназначен для обычного экрана, не VR. Эксклюзивный полноэкранный режим может перекрывать окно. Панель принимает мышь для перемещения.

## Проверка

`Start.cmd -SelfTest` — проверка живого хронометража, задержки на финише, расчёта отдельных секторов, ранних/запаздывающих пакетов, сохранения сравнений, BEST, сброса сессии, записи дельты, чтения памяти и ACC Broadcasting через тестовый локальный UDP-сервер.

`Start.cmd -Preview` — показать финишный результат с графиком, создать `preview.png`, `preview-graph.png` и общий `preview-with-graph.png`, затем закрыть окна. Только для Preview график включается принудительно, без сохранения настройки.

SelfTest дополнен проверками режимов соседей, смены/дублирования позиций, отсутствующих участников, питов, круговых, временной потери данных, действительных/недействительных рекордов, фиксации эталона, автоматического выбора сессии, старых и новых настроек. Обычный `-Demo` учитывает все сохранённые настройки, включая выключенный график. `-Preview` учитывает выбранные режимы сравнения и принудительно показывает график. Демонстрационные отрывы иллюстративны и обозначены статусом ДЕМО.

Проверочную сборку без замены основного архива можно сделать командой `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-Release.ps1 -OutputDirectory .\dist\validation`. Скрипт не публикует GitHub Release. Мини-сектора и сохранение истории заездов на диск не добавляются.

Формат памяти: [документация ACC в PyAccSharedMemory](https://github.com/rrennoir/PyAccSharedMemory/blob/main/ACCSharedMemoryDocumentationV1.8.12.pdf). Читаются только graphics-поля; доступ к памяти открыт только на чтение.

## График дельты после круга

В «Настройки» включите «Показывать график дельты после круга». По умолчанию выключен; `ShowDeltaGraph` сохраняется в preferences.json, старые настройки совместимы. Включение, выключение и затемнение применяются сразу. Если включить во время показа результата, график появится только на оставшееся время.

Панель появляется после полного записанного круга на те же 5 секунд, что и результат секторов: используется общее состояние Holding, отдельного таймера нет. При запаздывающем подтверждении финиша она появляется на остаток общего интервала. В меню, повторе и при смене сессии панель скрывается. Она не показывается во время прохождения круга.

Ширина 230, высота 40% основного окна, отступ 6 единиц WPF с учётом DPI. Панель центрируется по вертикали, перемещается вместе с оверлеем и использует его прозрачность и скругления. У правого края экрана переносится налево; если ни с одной стороны нет места, скрывается. Основное окно остаётся на месте.

Горизонтальная ось — прогресс трассы 0–100%, вертикальная — накопленная дельта в секундах. Зелёный участок означает выигрыш, красный — потерю; белая линия обозначает ноль. Справа сверху — итоговая разница с эталоном. Масштаб указан в секундах; подробность эталона доступна в подсказке.

Эталон фиксируется на старте круга: предыдущий или личный лучший в зависимости от настройки и типа сессии. Новый рекорд сравнивается с прежним рекордом. Изменение режима посреди круга изменяет живые показатели, а график завершённого круга сохраняет исходный эталон. Следующий круг использует новый выбор.

Точки сопоставляются по одинаковому прогрессу трассы. Между соседними точками допускается линейная интерполяция только при разрыве не больше 2 секунд и 5% трассы. Более крупные пропуски оставляют разрыв линии. Если предыдущий круг записан частично (выезд из питов или поздний запуск оверлея), используются только общие записанные участки двух кругов, без продолжения линии в неизвестные области. При отсутствии пригодной записи показывается «НЕТ ДАННЫХ». Итоговая дельта может быть известна и без линии. Приблизительный итог помечается ≈. Это измерения пакетов игры, а не непрерывная телеметрия с точностью 1 мс. Линия рассчитывается один раз и остаётся статичной до исчезновения.

SelfTest проверяет настройки, общий срок 5000 мс, мгновенное переключение, старый эталон при новом рекорде, отсутствие/разрывы точек, неполный круг, сброс сессии/меню/повтора, цвета и размещение справа/слева, включая мониторы с отрицательными координатами. Для EXE доступны `--demo`, `--preview` и `--self-test`.
## Проверять обновления без поездок в ACC

Тестер предназначен для работы с исходниками. Скачайте исходный код репозитория и дважды нажмите **Test.cmd** в папке проекта; также доступно `Start.cmd -TestMode`. В пользовательские EXE и ZIP тестер и его файлы не включены. Обычные `--demo` и `--preview` в EXE сохранены.

Откроются основной оверлей, график и панель управления тестом. Сразу показан готовый финиш, затем автоматически повторяется цикл: 5 секунд результата, 3 секунды ускоренного следующего круга. Тысячные и дельта обновляются вживую. «Показать финиш сейчас» воспроизводит выбранный сценарий с нуля, не дожидаясь круга. Можно отключить повтор, отдельно проехать следующий круг или сбросить сессию и проверить исчезновение графика.

По умолчанию выбран режим «Случайные круги»: каждый круг имеет новое время от 1:26 до 1:38 и новый профиль выигрыша/потери времени по трассе, иногда круг недействителен. Есть и фиксированные сценарии: обычный круг с зелёными/красными участками, новый личный рекорд, недействительный быстрый круг, пропущенные пакеты, частичная запись предыдущего круга и отсутствие его точек. Проверка «Нет точек» начинает с прочерков/НЕТ ДАННЫХ; следующий записанный круг может уже дать пригодный эталон в зависимости от режима сравнения.

График при входе в тест включён. Через обычные ⚙ Настройки можно проверить его выключение, включение, затемнение и выбор эталона. Тестовые preferences.json и position.json находятся в отдельной подпапке `TestMode` каталога данных, игровые настройки не изменяются. При следующем входе в тест график снова принудительно включается для наглядности. Закрытие панели управления или основного окна завершает тест.

Используется тот же класс Timing, запись точек, расчёт дельты, график и общий пятисекундный показ, что в игровом режиме. Телеметрия синтетическая: тест не подключается к ACC и не меняет broadcasting.json. Отрывы соседей и общий лучший в этом режиме иллюстративны. Проверку настоящих пакетов, задержек и Broadcasting выполняет `Start.cmd -SelfTest`; интерактивный тест не заменяет проверку соединения с игрой.

Для автоматического снимка теста: `Start.cmd -TestMode -Preview`. Файлы сохраняются в подпапку TestMode, включая `preview-test-controls.png` с панелью управления.

Для воспроизведения случайной последовательности запишите Seed из панели теста и запустите `Test.cmd -TestSeed 12345` или `Start.cmd -TestMode -TestSeed 12345`. При одинаковом Seed и последовательности действий круги повторяются. Без параметра каждый запуск выбирает новый Seed. Автоматические проверки тестера находятся в `TestDriveTests.ps1` и запускаются через SelfTest только из исходников; в EXE выполняются основные регрессионные проверки.
